# City Dataset 2026

> release_version

四天城市车辆采集的手机 GNSS/IMU 数据集。目录按日期组织；每个日期中的 `phone` 为手机数据，`true` 为该日期的 GNSS/INS 真值。

```text
YYYYMMDD/
  phone/<device>/
  true/*.ieout
```

# City Dataset 2026
