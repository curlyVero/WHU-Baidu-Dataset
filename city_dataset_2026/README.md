# City Dataset 2026

> release_version

城市车辆场景下采集的手机 GNSS/IMU 数据集。目录按日期组织，每个日期中的 `phone` 保存手机数据。当前发布版本不包含真值数据。

```text
YYYYMMDD/
  phone/<device>/
```

# City Dataset 2026

> release_version

A smartphone GNSS/IMU dataset collected in urban vehicle scenarios. Directories are organized by date, and `phone` under each date contains the smartphone data. Truth data are not included in the current public release.

```text
YYYYMMDD/
  phone/<device>/
```
